# Code of conduct

Be patient with beginners, explain assumptions and help people learn. Critique code and ideas respectfully. Harassment, discrimination, threats, spam and publishing someone else's private information are not welcome.

When discussing hardware, distinguish measured results from assumptions. Do not encourage unsafe wiring or tell someone to change a powered circuit.

Report conduct concerns privately to a repository maintainer using a contact channel they make available on GitHub. Do not post personal details in an issue. Maintainers may remove inappropriate content, close discussions or restrict participation to keep the project welcoming.
