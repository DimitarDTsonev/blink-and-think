OPEN ON YOUR PHONE

Scan. Join. Play.

Connect to a board to share its address.

This code opens the game. It does not connect your phone to Wi-Fi.

A smooth start, every time.

  1. Power the board.

    Connect USB and allow about 10–30 seconds for Wi-Fi. Saved credentials survive power-off.

  2. Join the same local network.

    Your phone can use 2.4 or 5 GHz if the router allows devices to communicate. ESP32 uses 2.4 GHz.

  3. Scan the code or open the address.

    Try http://color-game.local. If it doesn't resolve, use the device IP shown here or in Serial Monitor.

  4. Make it one tap away.

    On iPhone, open the game in Safari, tap Share, then Add to Home Screen. The board must still be powered and reachable.

First-time Wi-Fi setup

Join ESP32-Color-Setup using the unique password printed in Serial Monitor at 115200 baud. Open http://192.168.4.1, select your own 2.4 GHz network and save its password. Then return your phone to that network.

To change networks later: press and release EN, then hold BOOT for 3 seconds during the first 4 seconds after reset. Do not hold BOOT during reset.

The game won't open

Keep the board powered, check that both devices use the same LAN and try the current IP from Serial Monitor. A guest network, VPN or client isolation can block access. Reconnecting USB does not erase the game.

Rules & scoring

Start with 3 lights; finish a round to add another, up to 32. Classic extends the sequence, Reverse asks for it backwards and Shuffle makes a fresh sequence each round.

Exact light: 1 point. Other green: 0.5 points and continue. Wrong color or 30 seconds without an answer ends your turn. Best scores are separate for each mode and speed, saved when the turn ends.

Playing with friends

Everyone needs to see the physical LEDs. One person plays or controls the lights at a time; others can watch the score and take the next turn. There is no automatic queue or simultaneous multiplayer.
