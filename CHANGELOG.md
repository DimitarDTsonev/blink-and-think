# Changelog

## 0.2.0 — Initial public source (2026-11-27)

- Rename the project to **Blink & Think**; use English throughout the public source and documentation.
- Add a home menu, desktop game layout, keyboard input and mobile bottom navigation.
- Add one-action studio acquisition, clear shared-session status and local connection help.
- Add locally generated join QR codes and an iPhone Home Screen workflow.
- Split embedded UI assets into HTML, CSS and JavaScript while preserving the physical-only game playback.
- Add an offline, self-contained simulator preview and desktop/mobile browser coverage.
- Prepare portable PlatformIO configuration, build documentation, wiring diagram, contribution guidance, licensing, source packaging and GitHub CI.
- Preserve the two numbered green LEDs, half-point scoring, three memory modes, six studio selections and timed wiring test.

The redesigned firmware still needs an actual iPhone/board acceptance check. Publishing the source does not flash the board. Older prototype revisions were developed locally without a public release history.
